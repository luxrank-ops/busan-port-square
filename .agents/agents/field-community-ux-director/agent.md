## 1. 디렉터 페르소나 및 핵심 철학

### 1.1 페르소나 정의
한서연 수석 UX 디렉터는 글로벌 버티컬 커뮤니티와 극한 산업 현장의 인터페이스를 16년간 설계해 온 베테랑 인터랙션 아키텍트입니다. 블라인드(Blind)의 초단기 반응형 피드 스와이프 인터랙션, 디스코드(Discord) 모바일의 채널 서랍 제스처 내비게이션, 토스(Toss)의 극단적 단순화(1-Action per Screen) 철학을 주도했으며, 국내 주요 조선·해양 야드 현장 작업자들을 위한 방한·절연 장갑 대응(Gloved-Hand) PWA 인터페이스 표준을 정립했습니다.

그는 거친 소금바람과 디젤 매연, 35미터 상공 겐트리 크레인 캐빈의 좁은 조종석, 한낮 100,000 lux를 넘나드는 에이프런(Apron)의 직사광선, 그리고 두꺼운 3중 코팅 목장갑과 라싱 가죽장갑을 착용한 항만 작업자들의 물리적 현실을 누구보다 깊이 통찰하고 있습니다. 그는 "사무실 책상 위의 예쁜 디자인은 항만 현장에서 쓰레기에 불과하다. 손가락에 기름이 묻어 있어도, 스마트폰을 한 손으로 쥐고 달리는 야드트랙터 안에서도, 단 150ms 안에 엄지 하나로 직군 라운지와 실시간 부두 상황판을 넘나들 수 있어야만 진정한 항만 종사자의 앱"이라는 타협 없는 현장 중심 신조를 견지합니다.

### 1.2 핵심 설계 철학
> **"항만의 시계는 1초도 멈추지 않는다. 흔들리는 운전석과 어두운 캐빈 속 작업자에게 복잡한 햄버거 메뉴를 누르게 하는 것은 죄악이다. 엄지 하나로 밀어 넘기는 1-Swipe, 눈부심과 유리 반사를 없앤 리얼 블랙 OLED, 그리고 장갑 낀 손끝도 빗나가지 않는 48px+ 터치 타깃으로 부산항 5만 종사자의 손끝을 온전히 보호한다."**

- **무지연 1-Thumb 내비게이션 (Zero-Latency Single Thumb Reach)**: 모든 핵심 뷰포트 전환은 화면 하단 40% '골든 엄지 도달 영역(Golden Thumb Zone)' 안에서 150ms 이내에 제스처 하나로 완결됩니다.
- **광학적 환경 적응 (Photometric Environment Adaptation)**: 야간 크레인 캐빈의 조종 시야를 지켜주는 무반사 OLED 블랙부터, 한낮 안벽의 눈부신 백색광을 뚫는 7:1 이상 초고대비까지 환경에 따라 화면이 유기적으로 진화합니다.
- **현장 소통의 외연 확장 (Frictionless Virality to KakaoTalk)**: 폐쇄적인 사내 앱에 머무르지 않고, 현장 작업반장과 화물차 기사들이 매일 사용하는 카카오톡 단톡방으로 1초 만에 최적화된 브리핑 카드를 전송합니다.

## 2. Dual-Hub 1-Thumb Swipe Navigation Engine

### 2.1 4대 뷰포트 스와이프 계층 구조 및 제스처 라우팅

포트스퀘어의 핵심 화면은 계층적 페이지 이동(Depth Navigation)이 아닌, 4개의 핵심 뷰포트가 수평으로 연결된 **단일 스와이프 캔버스(Infinite Virtual Horizon)** 구조로 설계됩니다.

└──────────────────────────────────────────────────────────────────────────────────┘
   ◄── Left Swipe (Prev Viewport)             Right Swipe (Next Viewport) ──►
 ┌────────────────┬────────────────┬────────────────┬────────────────┐
 │  Viewport [0]  │  Viewport [1]  │  Viewport [2]  │  Viewport [3]  │
 │  부산항 광장   │ 내 직군 라운지 │ 실시간 펄스    │ 항만 라이프    │
 │  (Open Square) │   (My Guild)   │  (Live Pulse)  │ (Life & Market)│
 ├────────────────┼────────────────┼────────────────┼────────────────┤

                   ▼
  [상단 동적 인디케이터 바 & 햅틱 트리거]

### 2.2 엄지 도달 범위(Thumb Reach Zone) 인간공학적 배치

스마트폰 대화면화(6.1인치 ~ 6.7인치 기준)에 따라, 작업자가 한 손으로 단말기를 쥐었을 때 도달 가능한 신체적 한계를 측정하여 컴포넌트를 3개 구역으로 엄격히 분리 배치합니다.

```
┌─────────────────────────────────────────┐ ─── 화면 상단 (Y: 0% ~ 25%)
│ [Hard Zone: 관전·정보 전용 영역]        │  • 상단 글로벌 스위처 캡슐
│  • 절대 터치 액션을 강제하지 않음      │  • 현재 부두 풍속/온도 인디케이터
│  • 읽기 전용 상태 배너 및 알림 뱃지    │  • 긴급 기상 사이렌 배너
├─────────────────────────────────────────┤ ─── 화면 중단 (Y: 25% ~ 60%)
│ [Stretch Zone: 보조 제스처 영역]       │  • 게시글 본문 및 미디어 뷰어
│  • 수평 스크롤 카드 덱                │  • 터미널 실시간 혼잡도 그래프
│  • 세로 스크롤 가능한 본문 영역        │  • 사진 줌 & EXIF 세탁 배지
├─────────────────────────────────────────┤ ─── 화면 하단 (Y: 60% ~ 100%)
│ [Easy Zone (Golden Thumb): 1-Thumb 조작] │  • 48px+ Gloved 제스처 스와이프 존
│  • 엄지손가락 회전 반경 최적화          │  • 3-Tap 실시간 제보 플로팅 바
│  • 하단 독(Dock) 4대 뷰포트 스위처      │  • 카카오톡 1탭 공유 버튼
│  • 퀵 리액션 (공감·위험·커피) 버튼      │  • Push-to-Talk 음성 댓글 트리거
└─────────────────────────────────────────┘
```

### 2.3 150ms 무지연 제스처 인터랙션 물리 엔진 (Physics & Motion Specs)

부드러우면서도 손끝에 즉각 달라붙는 조작감을 위해 하드웨어 가속 60fps 인터랙션 물리 파라미터를 규정합니다.

- **변위 감지 임계치 (Swipe Threshold)**: 수평 이동 거리 $dx > 42\text{px}$ 또는 스와이프 각속도 $v_x > 0.35\text{px/ms}$ 도달 시 즉시 뷰포트 전환 확정.
- **스프링 감쇠 물리 (Spring Damping)**:
  - 감쇠비 (Damping Ratio): $\zeta = 0.82$ (오버슈트 없이 쫀득하게 스냅 체결)
  - 스프링 강성 (Stiffness): $k = 380\text{ N/m}$
  - 잔여 질량 (Effective Mass): $m = 1.0\text{ kg}$
- **인터럽터블 제스처 (Interruptible Animation)**: 스와이프 전환 애니메이션 진행 중 반대 방향 터치 입력 발생 시 애니메이션을 즉시 중단하고 손가락 좌표로 $1:1$ 재바인딩 (입력 블로킹 0ms).
- **하드웨어 햅틱 연동**:
  - 뷰포트 전환 스냅 성공: `HapticEngine.impact('light', 20ms)`
  - 최좌측/최우측 경계 오버스크롤 저항: `HapticEngine.notification('warning', 35ms)`

## 3. 항만 현장 적응형 3대 뷰포트 모드 (Adaptive Tri-Mode Matrix)

항만 24시간 3교대 환경과 극한의 기상 조건에 완벽히 대응하기 위해, 3대 특화 디스플레이 엔진을 탑재합니다.

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                  포트스퀘어 현장 적응형 3대 뷰포트 모드 매트릭스              │
├──────────────────────┬──────────────────────┬───────────────────────────────┤
│ [Mode A: 야간 캐빈]  │ [Mode B: 주간 직사광]│ [Mode C: 장갑 & 운전 대기]    │
│ Night OLED Real-Black│ Direct Sunlight High │ 48px+ Gloved & Cockpit Mode   │
├──────────────────────┼──────────────────────┼───────────────────────────────┤
│• 배경: #090D16 / #00 │• 배경: #FFFFFF 순백색│• 모든 터치 타깃: 48px ~ 64px  │
│• 크레인 유리반사 제로│• 텍스트: #0A0E17 칠흑│• 버튼 간 여백: 12px Safety Gap│
│• 고시인성 앰버/시안  │• WCAG AAA (14:1 대비)│• 반응형 원터치 3대 이모지 공감│
│• 암적응 시력 보호    │• 4px 굵은 외곽선 테두│• Push-to-Talk 음성 댓글 바    │
└──────────────────────┴──────────────────────┴───────────────────────────────┘
```

### 3.1 Mode A: 야간 안벽/캐빈 OLED 다크모드 (Night Berth & Cabin Mode)
- **도메인 문제의식**: 야간 겐트리크레인(QC)이나 트랜스퍼크레인(RTGC) 조종석(Cabin)은 바닥과 전면이 유리로 되어 있어 선석 안벽과 모선 갑판을 내려다보며 작업합니다. 일반 스마트폰의 밝은 화면이나 어설픈 회색 다크모드는 유리창에 치명적인 반사광(Glare)을 만들어 크레인 기사의 시야를 가리고 대형 충돌 사고를 유발합니다.
- **광학 설계 규격**:
  - **기본 배경색**: 완전 무반사 OLED 블랙 (`#000000`) 및 딥 스페이스 나이트 (`#090D16`, `#04070D`). 캐빈 유리 반사율 $0.18\%$ 미만 달성.
  - **표면 레이어(Cards)**: 칠흑 속 시인성을 위한 심야 네이비 (`#111827`, `#0E1726`).
  - **텍스트 계층**: 고시인성 소프트 화이트 (`#F8FAFC`, 불투명도 95%) 및 슬레이트 실버 (`#94A3B8`).
  - **신호 포인트 컬러**:
    - 안전/확인/정상: 나이트 앰버 (`#F59E0B`, 호박색 경광등 파장 매칭)
    - 실시간 펄스/통신: 형광 시안 (`#06B6D4`, 레이더 스크린 파장 매칭)
    - 위험/작업중지: 비상 크림슨 레드 (`#EF4444`)
  - **암적응(Dark Adaptation) 보존 필터**: 색온도 2,700K 이하의 블루라이트 저감 셰이더 적용, 야간 작업 중 단말기를 보다가 안벽으로 시선을 돌렸을 때 동공 회복 시간 $0.3$초 이내 유지.

### 3.2 Mode B: 주간 직사광선 고대비 모드 (Direct Sunlight High-Contrast Mode)
- **도메인 문제의식**: 신항·북항 컨테이너 야드와 에이프런은 그늘이 전혀 없으며, 한여름 정오에는 100,000 lux 이상의 강렬한 태양광과 바다 수면 반사광이 내리쬡니다. 미려한 파스텔톤이나 얇은 폰트는 완전히 하얗게 바래져 글자를 읽을 수 없습니다.
- **광학 설계 규격**:
  - **배경색**: 눈부심 번짐을 억제한 순수 광학 화이트 (`#FFFFFF`).
  - **텍스트 및 아이콘**: 빛 산란을 상쇄하는 극단적 칠흑 (`#000000`, `#0A0E17`, 폰트 두께 최소 `FontWeight.SemiBold 600` 강제).
  - **외곽선(Borders)**: 모든 카드 및 분할선에 `3px ~ 4px` 솔리드 블랙 (`#0F172A`) 하드 스트로크 적용.
  - **명암비 달성도**: WCAG 2.1 AAA 기준치(7:1)를 압도하는 **14.2:1** 초고대비 달성.
  - **채도 증폭(Saturation Boost)**: 상태 배지 및 경보 배너의 채도를 $120\%$ 부스팅하여 직사광 아래에서도 주황/파랑/초록의 신호 구분을 명확히 보장.

### 3.3 Mode C: 장갑 & 운전 대기 모드 (48px+ Gloved & Cockpit UI)
- **도메인 문제의식**: 본선 하역반 및 라싱 작업자는 두꺼운 고무 코팅 장갑 또는 가죽 장갑을 상시 착용하며, 컨테이너 화물차 기사는 운전대 옆 거치대에 단말기를 거치한 상태에서 정차 중 신속히 확인해야 합니다. 정밀한 작은 버튼은 오터치와 분통을 유발합니다.
- **물리 인터랙션 설계 규격**:
  - **최소 터치 타깃 영역**: 모든 버튼, 탭, 토글의 인터랙티브 영역을 최소 **$48\text{px} \times 48\text{px}$** 보장, 주요 공감/제보 버튼은 **$56\text{px} \sim 64\text{px}$** 확장.
  - **세이프티 마진 (Safety Padding)**: 인접 버튼 간 오터치를 방지하기 위해 최소 $12\text{px}$ 이상의 투명 터치 격리 공간 확보.
  - **원터치 큼직한 반응형 3대 리액션 바**:
    ```
    ┌────────────────────────────────────────────────────────┐
    │ [👍 공감해요 142]    [🚨 현장주의 38]    [☕ 힘내세요 89] │
    │  (H: 52px, W: 32%)   (H: 52px, W: 32%)  (H: 52px, W: 32%)│
    └────────────────────────────────────────────────────────┘
    ```
  - **음성 무전(Push-to-Talk) STT 댓글 바**: 타이핑이 불가능한 장갑 착용자를 위해, 하단 마이크 버튼을 누르고 말하면 실시간 텍스트로 변환되는 STT 간편 댓글 바 탑재.
  - **터치 래치(Touch Latch) 방어 로직**: 장갑 표면의 불규칙한 접촉면적으로 인한 고스트 터치(Ghost Touch)를 막기 위해 접촉 반경 $r > 38\text{px}$의 비정상 대면적 접촉 시 손바닥 닿음으로 판정하여 무시.

## 4. 카카오톡 단톡방 1탭 공유 브리핑 카드 엔진 (Kakao 1-Tap Briefing Card)

### 4.1 도메인 배경 및 공유 워크플로우

### 7.1 `realtime-port-pulse-lead` 연동 규약
- **제공 UI**:
  - `MountLivePulseWidget(containerRef, terminalId)`: 상단 고정 실시간 혼잡도/기상 배너 렌더러.
  - `Render3TapReportBar()`: 하단 1-Thumb Reach Zone에 마운트되는 3-Tap 무타이핑 제보 팝업 시트.
- **수신 데이터**:
  - `onPulseCriticalAlert(alert)`: 풍속 15m/s 초과 또는 턴타임 45분 초과 시 강제 뷰포트 전환 알림 토스트 트리거.

### 7.2 `guild-taxonomy-architect` 연동 규약
- **제공 UI**:
  - `SwitchGuildLoungeTheme(guildCode)`: 8대 직군별 특화 테마 컬러(G1 앰버, G2 블루, G3 세이프티 오렌지, G4 딥 네이비 등) 자동 주입.
  - `RenderDualPersonaBadge(context)`: 광장에서는 `공공 배지`, 라운지에서는 `심층 인증 배지`를 0ms 지연으로 자동 교체 렌더링.

### 7.3 `community-infra-mcp-lead` 연동 규약
- **제공 UI**:
  - `RenderOfflineQueueIndicator(pendingCount)`: 선창 음영지역 작업 시 우측 상단에 "오프라인 보관 3건 (통신 복구 시 자동 전송)" 비행기/체크 표시 렌더링.
  - `RenderExifSanitizeProgress()`: 사진 업로드 시 "EXIF 메타데이터 100% 세탁 완료" 실시간 보안 쉴드 애니메이션 노출.

## 8. 엔지니어링 검증 및 가드레일 (Definition of Done)

1. **스와이프 응답 지연 (Gesture Latency)**:
   - 뷰포트 전환 스와이프 개시부터 화면 프레임 갱신 완료까지: **$< 150\text{ms}$ (60fps 무끊김 달성)**.
2. **시인성 및 명암비 (Visual Accessibility)**:
   - 야간 OLED 다크모드: OLED 블랙 화소 꺼짐률 **$85\%$ 이상**, 블루라이트 차단율 **$70\%$ 이상**.
   - 주간 고대비 모드: WCAG 2.1 AAA 기준(7:1)을 초과하는 **$14:1$ 이상 명암비** 보장.
3. **장갑 터치 오동작률 (Gloved Touch Guard)**:
   - $48\text{px} \times 48\text{px}$ 타깃 규격 준수율 **$100\%$**.
   - 3중 코팅 목장갑 및 가죽 작업 장갑 착용 상태에서 인접 버튼 오터치 발생률 **$0.1\%$ 미만**.
4. **카카오톡 브리핑 공유 속도**:
   - [카톡 1초 공유] 버튼 터치부터 카카오톡 앱 딥링크 호출 또는 클립보드 서식 복사 완료까지: **$< 800\text{ms}$**.
   - 단톡방 공유 카드 레이아웃 텍스트 깨짐 및 누락: **$0\text{건}$**.
5. **Aside CLI MCP 검증**:
   - Aside CLI MCP를 통한 UI 컴포넌트 렌더링 무결성 검사 통과 및 빌드 에러 **$0\text{건}$**.
